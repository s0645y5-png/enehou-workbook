エネルギー法の全体像

地震で建物に入るエネルギー（必要量）と、建物が吸収できるエネルギー（保有量）を比べて安全を確かめる方法です。稀地震でダンパーの降伏を許容でき、その分を主架構の負担から差し引けるのが特徴です。ページ番号は『鋼構造建築物へのエネルギー法活用マニュアル』（緑本）です。

損傷限界（稀に発生する地震）告示第4／緑本4.2 P43〜

  1. 準備計算：mi, M, Td, Ai, Qfi, δi, kfi, Qdui, kdi, δdui
  2. 必要エネルギー Ed = ½·M·Vd²
  3. 吸収エネルギー We = Σ(Wfi + Wdei + Wdpi)、ni=2
  4. Ed ≦ We の確認
  5. C1（吸収エネルギーが Ed に達するベースシア）と層間変形角 1/200
  6. 残留変形（目標 1/1000）
  7. 地下・基礎（C1 時の応力で許容応力度設計）

安全限界（極めて稀に発生する地震）告示第6／緑本4.3 P50〜

  1. 準備計算：Qfui, Qdui, Qui, δfui, δdui, Re
  2. Es = ½·M·Vs² − We（We は ni=5 で計算し直す）
  3. 各層への配分 Esi（耐力分布のずれ pi の −n 乗）
  4. 主架構 Esfi とダンパー Esdi に分ける
  5. 必要累積塑性変形倍率 ηs ≦ 保有 ηc の確認
  6. 最大応答変位（告示の規定外だが確認推奨）

計算の流れと緑本の節

損傷限界：4.2.2 準備計算 → 4.2.3 Ed → 4.2.4 We → 4.2.6 C1 → 4.2.7 残留変形。安全限界：4.3.3 Es → 4.3.4 Esi → 4.3.5 配分と η → 4.3.6 最大応答変位 → 4.3.7 保有性能。

実務のポイント

  • Td は弾性の固有値ではなく、損傷限界時の等価剛性で求めた周期（SS7の固有値解析は初期剛性なので使えない）。P44〜45
  • ダンパーが降伏するか否かで We の計算が変わる。P47
  • 剛性比 k は通常 0.5〜2、耐力分担率 β は 0.1〜0.3 程度で k に応じて決める。β を βopt 以下にしておけばダンパーの耐力上昇を気にしなくてよい。P78〜79
  • We のただし書き：損傷限界〜保有水平耐力の台形部分も吸収エネルギーに数えられる。ただし全層の台形を全部足すのは過大評価。P64〜65
  • 4.3.6 の最大応答変位はかなり安全側。精度を上げるなら 5.2〜5.4 節。P59

最近の研究からの注意

建築研究報告155号 第7章に、4階建て鉄骨造の物流倉庫（座屈拘束ブレース）の計算例があります。従来の告示どおりに設計した建物でも、1.5Vs の地震や長く続く地震では1〜2階の梁端部が破断限界を超えるという結果でした。1.5Vs に耐えるには、ダンパー量を1.3倍程度、高強度鋼の柱、ノンスカラップの梁端などが必要とされています。

計算

各階の値はSS7の出力から入力します。セルにExcelの表をそのまま貼り付けると、右と下のセルに続けて入ります。

共通の条件

M は各階の重量の合計 Σw / 9.8 で自動計算します。Td は等価剛性による固有値解析（Dynamic PRO など）の結果を入れてください。

各階の値（上の階から）

kfi = Qfi/δi、δdui = Qdui/kdi、Qfui = kfi·δfui（サンプル建物の計算と同じバイリニア置換）。主架構の保有 ηc は 1/3·mηu·1.5·ab+2（ab：梁 2.0、柱 5/3）の小さい方。P35 解3.3.7

γdi をダンパー諸元から求める（座屈拘束ブレース）

緑本 P58 式(解4.3.4)：γdi = λLbr/(2EAbr)·(Lbr/Ld)²·sKd。sKd はダンパー1本の等価軸剛性 Ke×cos²θ で近似しています。

ダンパー量の目安

剛性比 k = KD/KF と耐力分担率 β = Qdui/Qui の関係です。β が βopt 付近のとき変位応答が最小になり、Uβ を超えるとダンパーの効きが落ちます。緑本 P78〜79 式(5.6.1)〜(5.6.3)

Uβ = k/(1+k) Uβopt = 1−1/√(1+k) βopt = k/(1+k+2√(1+k)) 各階の現在値

入力が大きい地震への余裕

安全限界の Vs を何倍かにしたとき、どこから足りなくなるかを見ます。建築研究報告155号では 1.5Vs を目標とした設計例が示されています。ここでは入力の倍率だけを変えており、梁端部の疲労評価式による限界変形は含みません。
