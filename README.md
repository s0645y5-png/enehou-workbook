# エネルギー法ワークブック

鋼構造建築物のエネルギー法（平17国交告第631号）を、『鋼構造建築物へのエネルギー法活用マニュアル』（緑本）に沿って学び、計算を試せる Web アプリです。

開く：https://s0645y5-png.github.io/enehou-workbook/

## できること
- **講座**：緑本 第Ⅰ編1〜5章と、第Ⅱ編 設計例4〜5 を順に学ぶ（ねらい → 本文の要点 → 例題 → 計算タブで試す → 確認問題と解説 → まとめ・質問メモ）
- **計算**：損傷限界・安全限界の計算（W_e のただし書き／告示どおりの切り替え、残留変形、E_si の配分、主架構・ダンパーの η）
- **設計の目安・余裕度・計算書**：剛性比 k と耐力分担率 β の目安、入力を 1.5 倍・2 倍にしたときの判定、計算過程の一覧

## iPhone・iPad で使うとき
Safari で開き、共有ボタン →「ホーム画面に追加」を選ぶと、アプリのように全画面で開けます（アイコン付き）。

## 注意
- 初期値は**架空のサンプル建物**（3層の物流倉庫）の値です。実際の検討では、各自の物件の値を入力してください。
- 学習の記録・入力した値・読み込んだ緑本PDFは、使っているブラウザの中にだけ保存されます（サーバーには送られません）。
- 緑本のPDFはこのリポジトリに含めていません。講座の最初の画面の「PDFを読み込む」から、お手元の緑本（章ごとに分けたPDF、ファイル名を `緑本_03_…pdf` のように章番号から始める）を読み込むと、各節から該当ページを開けます。
- 勉強と確認のための道具です。正式な構造計算書は、各社の検証済みの方法で作成してください。
